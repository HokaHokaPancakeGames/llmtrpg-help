APIキーの取り方

アプリの「API方式」を使うと、コピー＆貼り付けをせずに、ボタン1つで物語が進みます。
そのために必要な鍵（APIキー）は、Googleのサイトで無料で作れます。5分ほどで終わります。

はじめに知っておくこと

  • Googleアカウントが1つ必要です（Gmailを使っていればそれで大丈夫です）。
  • 無料で作れます。クレジットカードの登録は要りません。
  • APIキーはあなただけの鍵です。人に見せたり、SNSに貼ったりしないでください。
  • キーが無くても、コピペ方式ならアプリは今までどおり遊べます。API方式は「楽をするための道」です。

手順

  1. 1Google AI Studio を開く

    ブラウザで aistudio.google.com を開きます。 Googleアカウントでのログインを求められたらログインしてください。

  2. 2「APIキー」のページへ進む

    画面の中に 「Get API key」（または「APIキーを取得」）という項目があります。 左側のメニューか、画面右上のあたりにあります。それを押します。

    初めての場合は、利用規約への同意を求められます。内容を確認して進めてください。

  3. 3キーを作る

    「Create API key」（APIキーを作成）を押します。 プロジェクトを選ぶよう求められたら、提案されたものをそのまま選んで構いません。

    数秒で、AIza… のような長い文字列が表示されます。これがAPIキーです。

  4. 4キーをコピーする

    キーの横にあるコピーのボタンを押します。手で選んでコピーする場合は、 前後に空白や改行が入らないように気をつけてください。

    この画面を閉じる前にコピーしてください。キーは後から見直せないことがあります。 もし見失っても、同じ手順でもう一度作り直せます（古い鍵は消しておくと安心です）。

  5. 5アプリに貼り付ける

    LLMTRPGを開き、「AI接続設定」（タイトル画面、または世界作成画面の「AI接続設定を変更」）を開きます。

    方式を 「API方式」 に切り替え、APIキーの欄をタップして、コピーしたキーを貼り付けます。 モデルの一覧が読み込めれば成功です。

無料で使える回数について

Geminiの無料枠はモデルごとに1日の回数が決まっています。回数の多いモデルもあれば、1日20回ほどのモデルもあります。

アプリのモデル選択には、その目安が添えてあります。たくさん遊ぶ日は、回数の多い「Flash Lite」系を選ぶと安心です。 回数を使い切っても、翌日には戻ります（その日はコピペ方式に切り替えて続けることもできます）。

無料枠では、入力した内容がAIの学習に使われる場合があります。 実在の個人情報や、人に知られたくないことは書かないでください。

安全のために

  • APIキーはあなたの端末の中だけに保存されます。アプリの作者を含め、誰かに送られることはありません。
  • 他の人に教えないでください。鍵を知っている人は、あなたの無料枠を使えてしまいます。
  • うっかり人に見せてしまったら、AI Studio でその鍵を削除して、新しく作り直してください。

うまくいかないときは

モデルの一覧が出てこない
キーの前後に空白や改行が紛れていることがよくあります。もう一度、まるごとコピーし直して貼り付けてみてください。
「権限がありません」といった返事が返る
作ったばかりのキーは、使えるようになるまで少し時間がかかることがあります。数分おいてから試してください。 それでも直らない場合は、キーを作り直すのが早道です。
今日はもう返事が返ってこない
その日の無料枠を使い切った可能性があります。回数の多いモデルへ切り替えるか、翌日まで待つか、 コピペ方式に切り替えて続けてください。
画面の見た目がこの説明と違う
Google側の画面は時々変わります。「APIキー（API key）」という言葉を探せば、たいていたどり着けます。
